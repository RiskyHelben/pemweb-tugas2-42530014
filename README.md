Nama: Yohanes Risky Putra Helben Mbira
NIM: 42530014

Video penjelasan: https://youtu.be/L7cKx06INM8

## Cara menjalankan

```bash
npm install
npm start
```

Buka http://localhost:3000

## Rute

- `/` : katalog film, filter lewat query parameter (contoh `/?genre=action`)
- `/item/:id` : detail film lewat route parameter (contoh `/item/1`)
